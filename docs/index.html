04 / FAQ

Questions, answered.

What is Aura?

Aura is an open source live wallpaper manager built in compiled Rust specifically for COSMIC Desktop and modern Wayland compositors on Linux. It renders fluid 60 FPS animated loops and high-res static backgrounds with zero idle CPU wakeups and instant game pause.

Does it really use 0% GPU when playing games?

Yes. The instant a game or application enters fullscreen, Aura halts video decoding via MPV IPC. The GPU draw drops to 0.0%, returning 100% of your graphics card bandwidth and VRAM to your gameplay.

Which Linux distributions are supported?

Aura is designed for Pop!_OS and any distribution running COSMIC Desktop or Wayland layer-shell compositors, including CachyOS, Arch Linux, Fedora, openSUSE, and Debian.

How does dynamic auto-theming integrate with COSMIC?

Aura analyzes color vibrancy in your active wallpaper in real time. It calculates WCAG-compliant contrast tones and syncs accent colors directly with COSMIC Desktop's theming system, tinting your dock, active window borders, and UI highlights without manual configuration.

Where do the 9,400+ wallpapers come from?

Aura integrates curated online galleries directly into the interface: MotionBGS for handpicked looping live wallpapers (1080p and 4K), Wallhaven for high-resolution photography and digital art, and Microsoft Bing Daily for fresh UHD landscape imagery.

Is Aura free and open source? Any telemetry?

Aura is 100% free and open-source under the GNU General Public License v3.0 (GPL-3.0). There is zero telemetry, zero analytics tracking, no accounts to create, and no ads.

How do I summon the Quick Switcher HUD?

Aura doesn't enforce a preconfigured shortcut so it never conflicts with your workflow. In COSMIC Desktop, go to Settings → Keyboard → Custom Shortcuts, add your preferred key combination, and assign it to run the command aura switcher. The floating overlay pops up instantly over your active windows and dismisses automatically on click or wallpaper selection.

cargo install --git https://github.com/antwny/aura
terminal — aura-cli (x86_64-unknown-linux-gnu)
aura switcher # Open floating Quick Switcher HUD overlay (bind in COSMIC Settings)
aura next # Switch to the next wallpaper in active pool or playlist
aura prev # Switch to the previous wallpaper in active pool
aura toggle-pause # Manually pause or resume playback (drops to 0.0% GPU load)
aura # Launch the COSMIC graphical manager window (or 'aura gui')
aura apply <file> # Apply any video or image wallpaper directly from local path
aura stop # Stop wallpaper playback completely and terminate engine
aura status # Display connected displays, engine state, and active wallpaper
aura check-update # Check GitHub Releases for newer available versions
aura update # Atomically download and self-update binary to latest release
aura --daemon # Run headless in background on system startup (or '--hidden')
aura --version # Display installed Aura version and build metadata (or '-v')
aura help # Print command-line manual, flags, and usage options (or '-h')
COSMIC DESKTOP TIP Bind any of the hotkey commands in Settings → Keyboard → Custom Shortcuts to trigger live wallpapers with physical keys.
